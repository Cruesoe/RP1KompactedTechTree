**A smaller, tidier layout for the RP-1 tech tree that fits the whole tree on one R&D screen.**

The default RP-1 tree is huge and easy to get lost in. I reworked the layout into something neater without changing a single tech.

## Features

- Every RP-1 tech node is moved into a compact grid with columns in unlock order, so the whole tree fits in the default R&D view.
- Rows are reordered to untangle as many dependency lines as possible.
- Node icons are color coded by era, so you can see at a glance which period a tech belongs to.
- Lines to the Blue Sky (materials science) nodes are hidden for a cleaner look; the dependencies stay, and each Blue Sky node sits in line with the techs it unlocks.
- James Van Allen's research bonus text points to the science row in this layout.

## Requirements

- [RP-1 Express Install](https://github.com/KSP-RO/RP-1/wiki/RP-1-Express-Install)
- [Module Manager](https://github.com/sarbian/ModuleManager)

## Compatibility

Layout only: no tech costs, dependencies or parts are changed. Made for the current RP-1 tech tree.
Safe to add to or remove from an existing save.
